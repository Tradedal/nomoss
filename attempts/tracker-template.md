# Development tracker template

Name trackers `attempts/dev-attempts_<subject>.md` using established domain terms. Update the existing tracker when it covers the requested work. Keep the sections through Tasks. Add References and Supporting materials when they help deliver the work. Record delivery status in place of activity logs or session history.

## Tracker maintenance

Keep this section at the top of each tracker. Consolidate completed tasks into delivered outcomes and combine overlapping tasks as the work progresses.

State the result each task must deliver and the behavior that establishes completion. Include acceptance conditions in the task. Follow repository validation guidance.

Before marking a task complete, compare the requested result and initial behavior with what the affected workflow now delivers. Confirm that it preserves the required existing behavior.

## Scope statement

Start with the current state and describe the requested change. Record the permitted scope and any behavior the change must preserve. Ask a focused question when ambiguity would change the delivery.

## Direction

State two or three constraints or decisions that guide the work. Use the user's requirements and the repository's contracts.

## Completed work

- [x] Describe a delivered feature, improvement, or correction. Combine related outcomes as work progresses.

## Tasks

- [ ] Describe one outcome and the behavior that establishes completion. For a defect, cite evidence for the confirmed cause and explain how the change addresses it. Record any uncertainty, blocker, or reference beside the task it affects.

State tasks in plain English. Resolve overlap or conflicts before adding work. Include acceptance conditions in the relevant task.

## References

Link the specifications, source evidence, checked-in library guides, and repository patterns needed for the work.

## Supporting materials

Keep relevant files and screenshots with links to their saved locations. Capture requirements in plain English suitable for the repository.
